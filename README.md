# 🎮 Mario AI Simulation

## 📌 Overview
This project is an interactive web-based simulation that demonstrates the working of various Artificial Intelligence search and optimization algorithms using a grid-based environment inspired by classic Mario-style movement.

## 🚀 Features
- 🔍 Multiple AI Algorithms:
  - BFS, DFS, A*, Greedy, UCS
  - IDDFS, Hill Climbing, Simulated Annealing
  - Bidirectional Search
- 🎮 Interactive Simulation:
  - Step-by-step animated visualization
  - Real-time algorithm selection
  - Adjustable animation speed
- 🎨 Visual Representation:
 -🍄: Mario
 -🏁: Goal
 -🔴: Mario moving
 -🧱: Wall
 -🪙: Coin
 -👾: Enemy
 -🟦: Visited cell
 -🟩: Final path

## 🧠 Purpose
The goal of this project is to provide a visual and interactive way to understand how different AI algorithms explore search spaces and find optimal paths.
